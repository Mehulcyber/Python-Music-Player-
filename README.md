# 🎵 Python Music Player

A simple and user-friendly **Music Player application built with Python**.
This project provides a graphical interface for playing music and controlling playback using buttons.

## ✨ Features

* ▶️ Play music
* ⏸️ Pause music
* ⏭️ Play next song
* ⏮️ Play previous song
* 🎵 Select and play music files
* 🖥️ Simple graphical user interface
* 🖼️ Custom icons and background
* 🔊 Audio playback using Pygame

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – Graphical User Interface
* **Pygame** – Music/audio playback
* **OS / File Dialog** – File and folder handling

## ⚙️ Requirements

Make sure Python is installed on your computer.

Install Pygame using:

```bash
pip install pygame
```

Tkinter usually comes pre-installed with Python on Windows.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project folder

```bash
cd Python-Music-Player
```

### 3. Install the required library

```bash
pip install pygame
```

### 4. Run the project

```bash
python file.py
```

## 🎮 Controls

| Button      | Function               |
| ----------- | ---------------------- |
| ▶️ Play     | Play the selected song |
| ⏸️ Pause    | Pause the current song |
| ⏭️ Next     | Play the next song     |
| ⏮️ Previous | Play the previous song |
